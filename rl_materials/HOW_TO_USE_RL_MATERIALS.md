# 강화학습 재료 사용법

이 자료는 기존 파인튜닝된 Gemma v2에 이어서 강화학습하기 위한 입력,
보상 평가 기준, 참조 답안, 선호 비교를 담습니다. 판례 원문을 그대로
외우게 하는 학습 파일이나, 이미 강화학습을 마친 모델은 아닙니다.

최종 경로는 `.superloopy/evidence/frozen-release.json`의 `release`에 기록됩니다.
`data/case_rl/release_candidate`는 작업 중인 후보입니다. 완료 여부는 확정본의
`MATERIAL_STATUS.json`에서 `materials_complete`를 확인합니다.

## 모델에 전달할 것

`policy/train.jsonl`의 각 행이 하나의 강화학습 에피소드입니다.

- `claim_set`: 순서가 정해진 도면, 청구항 작성 지시, 필요한 경우 제공된
  판례 카드. 독립항 하나와 도면으로 뒷받침되는 종속항을 작성합니다.
- `patent_advisory`: 가상 사안의 사실관계, 관할과 기준 시점, 판례의 해당
  페이지 발췌문. 쟁점·적용·반대 논거·추가 확인사항을 설명합니다.

이미지 경로는 확정본 폴더를 기준으로 해석합니다. `messages`와 `images`만
모델 입력으로 사용하고 보상용 참조 답안, 선호 표지, 검토 보고서는 합치지 않습니다.

## 보상 평가에 전달할 것

같은 `episode_id`의 `reward/references.train.jsonl`에는 근거에 맞는 답안과
필수 판단 요소, 피해야 할 오류가 있습니다. 이는 가능한 정답의 한 예이며,
문장을 그대로 따라 썼는지로 보상을 주지 않습니다.

`reward/preferences.train.jsonl`에는 `chosen`과 `rejected`, 더 좋은 답안을
선택한 이유가 있습니다. 실제 생성 답안을 평가할 보상 체계를 준비하거나
선호 학습에 활용할 수 있습니다. 이 파일이 존재한다는 것만으로 온라인
강화학습을 실행했다고 보지는 않습니다.

채점은 `REWARD_PROTOCOL.md`에 따라 도면 근거, 종속관계, 판례 적용,
관할·시점, 불확실성 처리를 판단합니다. JSON 문법이나 인용 수만으로
법률적 타당성 점수를 주지 않습니다.

## 판례 어노테이션

청구항 본문과 판례 설명은 분리합니다. 모델이 선택한 `card_id`를 제공된
카드 목록에서 찾아 사건번호·법원·선고일·페이지·원문 해시를 표시합니다.
`rl_materials/contracts.py`의 `resolve_annotations`가 이 연결을 수행합니다.

`provided_during_drafting`는 작성할 때 실제로 전달한 판례 근거라는 뜻입니다.
모델 가중치 안에서 어떤 판례가 답변을 유발했는지 증명하는 표시는 아닙니다.
판례 법리는 청구항 표현을 검토할 근거이며, 도면에 없는 기술적 구성을
추가하는 근거로 쓰지 않습니다.

## 검증과 후속 학습

`calibration`은 보상 채점 검증용, `test`는 최종 평가용입니다. 이들의
답안과 선호 표지를 정책 모델이나 보상 모델의 학습 데이터로 합치지 않습니다.
기존 75개 시험 자료도 그대로 보존합니다.

자료 확정 후에는 기존 v2 어댑터에서 시작하는 학습 실행 환경, 실제 모델의
기반 가중치 리비전, 다중 도면 처리와 보상 연결을 별도로 검증합니다.
현재 작업은 GPU를 사용하지 않습니다. 재료의 검토 통과와 모델의 실제
청구항·자문 능력 검증은 별개의 결과입니다.
